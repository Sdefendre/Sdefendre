# Steve Defendre

I build local-first Mac, visionOS, and on-device AI software. I'm an Army veteran and Computer Science student at UMass Boston, and I ship products through [Defendre Solutions](https://defendresolutions.com).

## Products

### [Apple App Intents Skill](https://github.com/Sdefendre/apple-app-intents-skill)

A free, MIT-licensed agent skill that teaches coding agents to build iOS apps that work with Siri, Shortcuts, and Apple Intelligence. It includes current App Schema guidance, a Swift example, testing workflows, and a site at [sdefendre.github.io/apple-app-intents-skill](https://sdefendre.github.io/apple-app-intents-skill/).

### [FreeVoiceTranscribe](https://github.com/Sdefendre/freevoicetranscribe)

Private, local hold-to-talk dictation for Apple Silicon Macs. Hold a global hotkey, speak, and release to insert the transcript into the focused field, using macOS Accessibility APIs and on-device Whisper through MLX. Free, MIT-licensed open-source software, run from source. Site: [sdefendre.github.io/freevoicetranscribe](https://sdefendre.github.io/freevoicetranscribe/).

### [LingBot Spatial](https://github.com/Sdefendre/lingbot-vision-pro)

A visionOS demo that brings LingBot-Map streaming 3D reconstruction into Apple Vision Pro with SwiftUI and RealityKit. It includes a glass control window, a table-scale volumetric preview, and a mixed immersive walkthrough of poses, keyframe frustums, and colored geometry.

### [Spindle City](https://github.com/Sdefendre/spindle-city)

A street-level exploration and driving game of Fall River, and a second bounded New Bedford map, built from OpenStreetMap extracts. A native Godot 4 port lives alongside the earlier browser version.

### [UMB Campus 3D](https://github.com/Sdefendre/umb-campus-3d)

A phone-first 3D wayfinding app for the UMass Boston campus. Load a class schedule (.ics, PDF, or pasted text) and follow a glowing walking route to the right building door, with a "leave in N minutes" countdown for your next class and a step-free route option. Parsing and routing run entirely on your device. Built with three.js and OpenStreetMap data as an installable PWA. Site: [sdefendre.github.io/umb-campus-3d](https://sdefendre.github.io/umb-campus-3d/).

### [WealthWise](https://github.com/Sdefendre/Wealthwise)

A Next.js money dashboard. Import a CSV or PDF bank statement, chart the rows, or start from the bundled sample. No Plaid and no live bank login. MIT licensed. Site: [sdefendre.github.io/Wealthwise](https://sdefendre.github.io/Wealthwise/).
