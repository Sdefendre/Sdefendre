## Selected technical work

### [FreeVoiceTranscribe](https://github.com/Sdefendre/freevoicetranscribe) — working, open source

Private, local hold-to-talk dictation for Apple Silicon Macs. The Python application combines global hotkeys, macOS Accessibility APIs, local Whisper inference through MLX, privacy-conscious storage, packaging, tests, and release automation.

### [Traces](https://github.com/Sdefendre/traces-app) — active prototype, open source

A local-first knowledge workspace with an Electron and Next.js desktop shell, Markdown editing, a 3D knowledge graph, file-system tooling, and a multi-provider AI assistant. Built with TypeScript, React Three Fiber, CodeMirror, and Zustand.

### [LingBot Spatial](https://github.com/Sdefendre/lingbot-vision-pro) — working visionOS demo, open source

Streaming 3D reconstruction concepts brought into Apple Vision Pro with SwiftUI and RealityKit. The project renders point clouds, camera paths, keyframe frustums, volumetric previews, and an immersive walkthrough from demo or exported reconstruction data.

### WealthWise — private, in development

A personal-finance dashboard exploring statement ingestion, transaction workflows, analytics, authentication, and a reactive Convex data layer. The repository remains private while the current data migration and import flow are completed, so I do not link to inaccessible source.

### [Airline Flight Schedule](https://github.com/Sdefendre/AirlineFlightSchedule) — academic Java project

A command-line scheduling system that models airlines, flights, departures, and arrivals. Recent improvements add JUnit coverage, safer input handling, and constant-time airline lookup with a `LinkedHashMap`.
